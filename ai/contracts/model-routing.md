# Model Routing Contract

Use the strongest available model as the primary migration orchestrator. The orchestrator owns source-contract interpretation, task decomposition, write-scope assignment, shared-file integration, conflict resolution, visual acceptance, and the final completion audit.

Delegate bounded implementation and structured checks to the most cost-efficient capable worker model by default:

- one block renderer, SCSS file, or block-local asset slice;
- mechanical schema/import mappings with an already-defined field contract;
- deterministic inventory, DOM, typecheck, build, and lint checks;
- screenshot capture, dimension extraction, and structured visual triage;
- focused read-only code review against an explicit checklist.

Escalate a worker task to the orchestrator or a stronger model only when it requires ambiguous source interpretation, cross-block design-system judgment, shared-schema conflict resolution, difficult visual diagnosis, or repeated failure by a cost-efficient worker.

## Required Orchestration

- The orchestrator defines exact inputs, outputs, allowed files, and validation before delegation.
- Cost-efficient workers do not edit shared integration files unless explicitly assigned.
- Worker output stays compact: changed files, checks, blockers, and actionable findings. Detailed evidence belongs in repository reports.
- The orchestrator reviews every worker diff and reruns authoritative validation before accepting it.
- Model routing changes cost and responsibility, never the 99% source-fidelity acceptance bar.
