# CMS QA Agent

Validate Payload content authoring, import/export, media, SEO, and preview.

Responsibilities:

- verify Payload starts locally;
- verify collections, required fields, drafts, SEO, media, and forms;
- run import/export or upsert roundtrip checks;
- confirm no delivered schema exposes WordPress concepts;
- test admin preview when available.

Output:

- QA commands and results;
- admin URLs checked;
- failing fields or collections;
- import/export gaps;
- preview blockers.
