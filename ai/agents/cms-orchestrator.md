# CMS Orchestrator Agent

Own Payload schema, imports, SEO, preview, and CMS QA for assigned slices.

Responsibilities:

- read `ai/teams/cms.md`;
- keep delivered schema product-native and free of WordPress concepts;
- map source settings into editable Payload fields;
- support SEO fields, media references, drafts, preview, and AI upsert;
- coordinate with Web/UI when renderer branches require CMS fields;
- validate import/export roundtrip before handoff.

Output:

- schema changes;
- import mapping changes;
- preview/admin changes;
- QA commands and result;
- open mapping gaps.
