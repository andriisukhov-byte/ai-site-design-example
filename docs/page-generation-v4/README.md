# Как работает система генерации страниц — две презентации

Один реальный прогон системы, разобранный на две части. Обе на русском, слайды 1600×900.

| Файл | Что внутри | Слайдов |
|---|---|---|
| `pitch-without-instruction.pdf` | **Демонстрация.** Что система получает на входе, что выдаёт на выходе, как проверяет саму себя, где всё-таки нужен человек. Без команд и без кода — для тех, кто впервые слышит про этот подход. | 26 |
| `pitch-instruction.pdf` | **Инструкция.** Те же 14 шагов, но с командами, чек-листом приёмки, списком ловушек и двумя сценариями, которые встретятся обязательно. Для тех, кто будет делать. | 17 |

Смотреть в таком порядке: сначала демонстрация, потом инструкция.

## Прогон, на котором это снято

Страница `/ai-receptionist-for-dental-clinics/` — отраслевая посадочная из 9 секций, все из библиотеки, новых секций ноль.
Батч: `data/ai-page-generation/2026-09-ai-receptionist-dental/` (бриф, страница, отчёт о приёмке).
Статус: черновик в Payload, id 165. Не публиковать, пока маркетинг не подтвердит четыре цифры, перечисленные в брифе.

Что нашли проверки: 7 замечаний гейта копирайта, 3 дефекта вёрстки, которые видны только на скриншотах, и 33 замечания независимой проверки за четыре круга — включая настройку «не показывать в поиске», случайно скопированную с тестовой страницы.

## Пересобрать PDF

Исходники в `deck-source/`: два HTML, общий `deck.css`, папка `img/`. Открыть HTML в Chromium и напечатать в PDF 1600×900 с фонами, либо прогнать Playwright'ом:

```js
await page.pdf({ path: 'out.pdf', width: '1600px', height: '900px', printBackground: true })
```
